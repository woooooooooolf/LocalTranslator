## V1.1.0 更新说明

新增日语↔简体中文文字翻译，并修正界面语言对应的默认翻译方向。

- 新增 M2M100 418M INT8 中日共享模型：在“本地模型”下载一次即可双向使用，下载量约 474.2 MiB；两种方向共用权重，可在程序内删除。
- 默认中文界面选择“英语→中文”；切换 English 后选择“中文→英语”，切回中文恢复“英语→中文”。语言切换保留现有输入和译文。
- 中英翻译继续使用原有 Argos 模型。中日模型采用固定版本的社区 INT8 转换，保留来源与许可；所有下载均校验内置 SHA-256，取消或失败不会启用半成品。
- 保持本机 CPU 离线翻译、内存中处理和主动复制；不保存草稿、翻译历史或内容日志，不添加内容审核与题材过滤。只处理文字，不含 OCR、图片识字或文档导入导出。

### 下载与升级

下载 `LocalTranslator_V1.1.0_Windows_x64.exe`，放到有写入权限的文件夹运行。需要 Windows 11 x64 或 Windows 10 2004+ x64，以及系统已安装 Microsoft Edge WebView2 Runtime。无需 Python、Node.js、CUDA 或附带应用 DLL。

可将新版 EXE 放在原有 `models` 文件夹旁，继续使用已安装的中英模型。关闭旧版后运行新版，在“本地模型”中按需下载中日模型。附件不包含模型，安装模型后可断网翻译。使用 `SHA256SUMS.txt` 核对 EXE 文件。本次仅发布 Windows x64，V1.0.0 原有资产保持不变。

### 模型效果与来源

中日使用 Meta M2M100 418M 的社区 CTranslate2 INT8 转换（`auralmira/m2m100-418M-ct2-int8`），并非 Meta 官方转换包，基座模型采用 MIT 许可。具体固定版本、署名与实测见 [中日模型评测](https://github.com/woooooooooolf/LocalTranslator/blob/V1.1.0/docs/JAPANESE_MODEL_EVALUATION.md)。

翻译效果取决于模型，可能出现生硬表达、误译或漏译；实测中亲属称谓、人名和语气仍有错误。不设题材限制不代表所有文本都能被准确理解。M2M100 418M 在 Ryzen 7 5700G、4 推理线程下的短句测试中，原生中位耗时约 0.46 秒，进程峰值工作集约 696 MiB；其他硬件与长文本表现会不同。
