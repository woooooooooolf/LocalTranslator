## LocalTranslator V1.0.0

首个公开版本，提供 Windows x64 单 EXE 中英文文字翻译。

- 默认中文界面，可切换 English；界面切换同步选择中文→英语或英语→中文，保留现有输入输出。
- 原生 CPU 推理；模型在程序内按需下载、校验、安装或删除，下载后可断网翻译。
- 原文与译文在内存中处理，无草稿、历史、内容日志或文件导出；手动复制才写入剪贴板。
- 深浅主题、随窗口扩展的编辑区域；临时 WebView2 InPrivate 会话。

下载 `LocalTranslator_V1.0.0_Windows_x64.exe`，放到可写文件夹运行。需要 Windows 11 x64 或 Windows 10 2004+ x64，以及系统 WebView2 Runtime。首次仅分发 EXE，模型通过“本地模型”页面下载。暂不提供 Linux/macOS。

---

First public release: a standalone Windows x64 EXE for Chinese ↔ English text translation.

- Chinese interface by default, with an English switch and automatic translation-direction selection. Existing input and output remain unchanged.
- Native CPU inference with in-app model download, verification, installation and deletion. Translation works offline after models are installed.
- In-memory text processing; no drafts, history, content logs or file export. Clipboard writes require an explicit copy action.
- Light/dark themes, expanding editors and temporary WebView2 InPrivate sessions.

Download `LocalTranslator_V1.0.0_Windows_x64.exe` and run it from a writable folder. Requires Windows 11 x64 or Windows 10 2004+ x64 and the system WebView2 Runtime. Download models from the Models page on first use. Linux/macOS builds are not included.

Use `SHA256SUMS.txt` to verify the executable. Model weights are downloaded separately; attribution is preserved in each model's README and the app's third-party notices.
